# External component review

Answer all applicable questions:

1. Is the upstream source canonical and actively maintained enough for this role?
2. What exact license covers source, binaries, model weights, data, and assets?
3. Do distribution method or build flags change the effective license?
4. Is commercial use allowed? Are attribution, source disclosure, or share-alike
   duties compatible with the planned distribution?
5. Does any required workflow need an account, API key, payment card, free trial,
   quota, or proprietary cloud?
6. Can it run on a CPU-only developer machine? What are RAM, disk, and download
   requirements, and are large downloads explicit?
7. What data leaves the device? Are user videos or transcripts uploaded?
8. Is there a smaller standard-library or already-installed solution?
9. Can the component be replaced behind an adapter and removed cleanly?
10. Has the decision and required attribution been added to project docs?

For video-source tooling, also verify that the intended use does not bypass DRM or
encourage access outside the user's rights.
